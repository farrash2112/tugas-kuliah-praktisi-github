# Bridging Global Infrastructure to Address Local Challenges in HPC
**Studi kasus:** simulasi perhitungan numerik yang membandingkan eksekusi serial dan multiprocessing.

**Jalankan:** `python hpc_demo.py` atau `python hpc_demo.py --n 200000 --workers 4`.

Skrip menampilkan waktu serial, waktu paralel, speedup, dan pengecekan konsistensi hasil. Ini demonstrasi multiprocessing di satu komputer, bukan benchmark klaster HPC.
