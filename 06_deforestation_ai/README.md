# Attributing Direct Drivers to Deforestation Alerts with Satellite Imagery and AI
**Studi kasus:** mengelompokkan alert deforestasi ke kategori kemungkinan pemicu langsung: ekspansi pertanian, pembangunan jalan, atau penebangan.

**Jalankan:** `python deforestation_driver.py`.

Model Random Forest menggunakan fitur numerik sintetis bergaya penginderaan jauh. Tidak ada citra satelit asli dalam paket ini. Untuk penggunaan nyata, perlu citra dan label lapangan tervalidasi; korelasi fitur bukan bukti sebab-akibat.
