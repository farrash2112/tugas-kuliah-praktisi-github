# 6 Studi Kasus: Data, AI, HPC, GIS, HCI, dan Deforestasi

Paket ini berisi enam proyek Python yang dapat dijalankan dan dikembangkan untuk GitHub.

## Daftar proyek
1. `01_analytics_ai` — analitik penjualan dan klasifikasi kategori transaksi.
2. `02_hpc` — perbandingan komputasi serial dan paralel.
3. `03_gis_career_industry` — peta peluang karier ilustratif berbasis GIS.
4. `04_intro_machine_learning` — klasifikasi spesies bunga Iris.
5. `05_hci_visualization` — dashboard interaktif dengan Streamlit.
6. `06_deforestation_ai` — klasifikasi faktor pemicu peringatan deforestasi dengan fitur sintetis.

## Instalasi
Gunakan Python 3.10+ dan jalankan dari folder utama:
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```
Baca README di setiap folder untuk perintah menjalankan.

**Catatan:** data penjualan, GIS, dan deforestasi adalah data ilustratif/sintetis, bukan data lapangan aktual. Model deforestasi hanya demonstrasi pembelajaran dan tidak membuktikan sebab-akibat.

## Unggah ke GitHub
Ekstrak ZIP, buat repositori baru, lalu unggah isi folder ini. Jangan unggah `.venv/` atau informasi rahasia.
