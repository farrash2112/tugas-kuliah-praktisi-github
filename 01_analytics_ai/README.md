# Make Sense of Data with Analytics and AI
**Studi kasus:** toko daring ingin memahami produk penyumbang pendapatan dan mengklasifikasikan transaksi sebagai penjualan tinggi/rendah berdasarkan atribut transaksi.

**Jalankan:** `python analytics_ai.py`

Skrip membuat data sintetis, mencetak ringkasan analitik, melatih Decision Tree, menampilkan metrik, dan menyimpan grafik `ringkasan_penjualan.png`.
